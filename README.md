# 地图壁纸 · 逐物体建模试玩

在线试玩：<https://air-sage.github.io/map-wallpaper-3d-models/>

把《赛尔号》地图壁纸里的物体逐个单独建模、配上贴图，再按原画里的位置摆回去，拼成可以走进去的 3D 场景。
打开链接后在列表里点一张地图即可。

## 操作

- 移动：WASD 或方向键，Shift 跑，空格跳（手机上用左下角摇杆和「跳」按钮）
- 视角：按住鼠标拖动转向，滚轮调远近，V 在第三人称 / 第一人称 / 原图机位之间切换
- 其他：P 对照原图，`[` `]` 换上一张 / 下一张，R 回起点，M 回地图列表

## 这个仓库里有什么

- `play/`：试玩页（单个 HTML + three.js），`play/site.json` 是地图列表
- `maps/<编号>/`：每张地图的物体清单 `objects.json`、地面图、原图，以及 `models/` 里每个物体的模型
  （贴图为 WebP，网格做了量化和 meshopt 压缩，每张地图约 2–3 MB）

这里的文件都是从制作目录自动生成的，不要直接改。
